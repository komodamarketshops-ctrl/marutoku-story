# 丸徳マーケット ストーリーズ自動投稿

営業時間の画像を毎日Instagramストーリーズに自動で投稿します。

- 平日は15:00、土日祝は11:00（日本の祝日にも対応）
- `images/` に入れた画像を、ファイル名の順に1日1枚ずつ使います。最後まで行ったら最初に戻ります
- 動かすのはGitHub Actions（無料）です。PCやClaudeを閉じていても動きます
- 投稿に失敗した日は、GitHubに登録したメールアドレスに通知が届きます

## 仕組み

```
GitHub Actions（毎日2回起動）
  └ post_story.py が、今日が平日か土日祝かを判定
      └ 投稿時刻まで待つ → Instagram公式APIでストーリーズに投稿 → posts.log に記録
```

## セットアップ（最初の1回だけ）

### 1. Instagram と Facebookページがつながっているか確認する

Instagramアプリで「プロフィール → プロフェッショナルダッシュボード（またはアカウントセンター）」を開き、
丸徳マーケットの **Facebookページ** とリンクされていることを確認します。
リンクされていなければ、ここでリンクしてください。

### 2. 画像を用意する

- 形式は **JPEG（.jpg）**、サイズは **8MB以下**
- 縦長の **1080×1920（9:16）** がおすすめです
- `01.jpg`, `02.jpg`, … のように、出したい順に番号を付けて `images/` に入れます

### 3. GitHub にリポジトリを作る

1. https://github.com でアカウントを作成します（すでにあれば不要）
2. 新しいリポジトリを **Public（公開）** で作成します（例: `marutoku-story`）
   - Instagramが画像を取りに来られるように、公開にする必要があります。画像はどのみちストーリーズで公開されるものです
   - アクセストークンは次の手順5の「Secrets」に入れるので、公開されません
3. このフォルダの中身（`.github` フォルダも含めて）をすべてアップロードします

### 4. Meta のアクセストークンを取得する

1. https://developers.facebook.com でログインし、「マイアプリ → アプリを作成」を選びます
   - 種類は「ビジネス」（または「その他」→「ビジネス」）を選びます
   - 審査は不要です。自分のアカウントに投稿するだけなら「開発モード」のままで使えます
2. 「ツール → グラフAPIエクスプローラ」を開き、右側で作ったアプリを選びます
3. 「アクセス許可」に次の権限を追加して、「Generate Access Token」を押します
   - `instagram_basic`
   - `instagram_content_publish`
   - `pages_show_list`
   - `pages_read_engagement`
   - `business_management`
4. 表示されたトークンを「ツール → アクセストークンデバッガー」に貼り、
   「アクセストークンを延長」を押します（**長期ユーザートークン**になります）
5. グラフAPIエクスプローラに戻り、長期トークンに入れ替えてから次を実行します
   - `me/accounts` → 丸徳マーケットのページの `access_token`（**ページトークン**）と `id`（ページID）を控えます
6. 次に、トークンをページトークンに入れ替えて、`{ページID}?fields=instagram_business_account` を実行します
   - 出てきた `instagram_business_account.id` が **IG_USER_ID** です

長期ユーザートークンから取得したページトークンには、基本的に有効期限がありません。
ただし、Facebookのパスワードを変更すると無効になるので、その場合は手順4をやり直してください。

### 5. GitHub にトークンを登録する

リポジトリの「Settings → Secrets and variables → Actions → New repository secret」から、次の2つを登録します。

| 名前 | 値 |
|---|---|
| `IG_USER_ID` | 手順4-6で控えたID |
| `IG_ACCESS_TOKEN` | 手順4-5で控えたページトークン |

### 6. テストする

リポジトリの「Actions → ストーリーズ自動投稿 → Run workflow」から実行します。

- `dry-run`: これから2週間の予定（日付・時刻・使う画像）が表示されます。投稿はしません
- `post-now`: 今すぐ1枚投稿します。ストーリーズに出れば設定は完了です

あとは毎日自動で投稿されます。

## 運用

| やりたいこと | 方法 |
|---|---|
| 画像を差し替え・追加したい | `images/` のファイルを入れ替える |
| 投稿時刻を変えたい | `post_story.py` の `WEEKDAY_TIME` / `HOLIDAY_TIME` と、`.github/workflows/post-story.yml` の cron を変える |
| 一時的に止めたい | Actions → ストーリーズ自動投稿 → 「…」→ Disable workflow |
| 投稿の履歴を見たい | `posts.log` を見る |

### 注意

- GitHubの起動は数分遅れることがあるので、20分前に起動して投稿時刻まで待つようにしています。
  それでもGitHubが混んでいる日は、数分遅れて投稿されることがあります
- 年末年始など、祝日ではない臨時休業日には対応していません。必要なら追加できます
